Group Project

A precision-agriculture platform combining IoT sensors, real-time data pipelines, and ML models to automate irrigation decisions and crop monitoring for mixed-vegetable farming. Sensor data (soil moisture, temperature, humidity, pressure, solar radiation) streams from ESP32 devices through Apache Kafka before reaching the ML layer and a web/mobile dashboard.
